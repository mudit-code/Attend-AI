# 📚 AttendAI Documentation Hub

This directory organizes all project documentation, architecture design files, institutional directories, and analysis reports.

---

## 📂 Folder Structure

### 1. `accounts/` — Institutional Credentials & Directories
Contains all student, faculty, HOD, and administrator accounts and credentials across CSE and ECE branches:
- **`Accounts.docx`**: Modern Microsoft Word directory (Double-clickable).
- **`accounts.txt`**: Plain text format (Notepad-compatible).
- **`AttendAI_Institutional_Accounts_Directory.docx`**: Complete detailed Word document with tables.
- **`AttendAI_Institutional_Accounts_Directory.doc`**: Word-compatible document.
- **`AttendAI_Institutional_Accounts_Directory.md`**: Markdown format.

### 2. `architecture/` — System Architecture & Design
Contains technical specifications, system architecture diagrams, and workflow guides:
- **`AttendAI_System_Architecture_and_Design_Document.pdf`**: Official PDF architecture specification.
- **`AttendAI_System_Architecture_and_Design_Document.docx`**: Word version of architecture document.
- **`AttendAI_System_Architecture_and_Design_Document.md`**: Markdown version.
- **`AttendAI_System_Architecture_and_System_Diagrams.docx`**: System architecture diagrams and flowcharts.
- **`College Attendance System Architecture & System Design Plan.docx`**: Foundational architecture & design plan.
- **`ATTENDAI_WORKFLOW_GUIDE.txt`**: End-to-end multi-role setup and operational guide.

### 3. `reports/` — Analysis Reports
Comparative audits and GitHub repository analysis reports:
- **`College_ERP_GitHub_Analysis_Report.md`**: Analysis of college ERP patterns and integrations.
- **`Four_Repositories_Comprehensive_System_Analysis_Report.md`**: Comprehensive 4-repository architecture study.
- **`KIT_ERP_Complete_System_Analysis_Report.md`**: ERP feature gap and functionality report.
